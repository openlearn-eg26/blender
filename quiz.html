Quiz: Lessons 1 to 6

Twelve short questions on the plant pot project. Pick your answer in your head, then open the answer to check. Nothing is saved or sent.

1. In the default scene, which three objects do you see in the Outliner?

  1. Camera, Light, World only
  2. Cube, Camera, Light
  3. Cube, Plane, Sphere
Show answer

B: Cube, Camera, Light. The default scene has a cube, a camera and a light (Lesson 1).

2. Which key shows the whole scene again if you get lost?

  1. F12
  2. Home
  3. Tab
Show answer

B: Home. Home shows the whole scene. Numpad . focuses on the selected object (Lesson 1).

3. Your mouse has no middle button. Which Preferences option helps?

  1. Emulate Numpad
  2. Enable Timeline
  3. Emulate 3 Button Mouse
Show answer

C: Emulate 3 Button Mouse. Emulate 3 Button Mouse (Edit > Preferences > Input). Then you orbit with Alt + left mouse button (Lesson 1).

4. What does pressing G, then X, then 2, then Enter do?

  1. Scales it to 2 times its size
  2. Moves the object 2 meters along the X axis
  3. Rotates it 2 degrees
Show answer

B: Moves the object 2 meters along the X axis. G moves, X limits the move to the X axis, and 2 is the distance in meters (Lesson 2).

5. Which command turns the cube 45 degrees around the Z axis?

  1. S, Z, 45, Enter
  2. R, Z, 45, Enter
  3. G, Z, 45, Enter
Show answer

B: R, Z, 45, Enter. R is Rotate. Add Z for the axis and type 45 for the angle (Lesson 2).

6. Which shortcut resets the location of the selected object to zero?

  1. Ctrl + Z
  2. Shift + D
  3. Alt + G
Show answer

C: Alt + G. Alt + G resets location, Alt + R rotation and Alt + S scale (Lesson 2).

7. In Edit Mode, which number key switches to Face Select mode?

  1. 3
  2. 2
  3. 1
Show answer

A: 3. 1 is vertices, 2 is edges and 3 is faces (Lesson 3).

8. Which tool makes a smaller face inside the selected face?

  1. Bevel (Ctrl + B)
  2. Loop Cut (Ctrl + R)
  3. Inset (I)
Show answer

C: Inset (I). Inset (I) makes a face inside the face. Extrude (E) then pushes it down to make the hollow (Lesson 3).

9. In the Material settings, what does a higher Roughness value do?

  1. The object gets bigger
  2. The surface gets more metallic
  3. The surface gets rougher and less shiny
Show answer

C: The surface gets rougher and less shiny. The higher the Roughness, the rougher and less shiny the surface (Lesson 4).

10. Which kind of light gives a soft shadow in the pot scene?

  1. No light at all
  2. A second camera
  3. Area light
Show answer

C: Area light. An Area light gives a soft shadow (Lesson 5).

11. Which key starts a render?

  1. Numpad 0
  2. Ctrl + R
  3. F12
Show answer

C: F12. F12 opens the render window and builds the image. Numpad 0 enters or leaves the camera view (Lessons 5 and 6).

12. After a render, how do you save the image from the render window?

  1. Image > Save As, then choose PNG
  2. Press Tab
  3. Press Home
Show answer

A: Image > Save As, then choose PNG. In the render window choose Image > Save As and save as PNG. Save the project with Ctrl + S too (Lesson 6).
