Bonus lesson

The Boolean Modifier

Cookie cutters, keyholes and drilled holes all take one shape out of another. The Boolean modifier combines meshes with a Boolean operation: it can cut one object out of another, join them into one solid, or keep only the part where they overlap. You model two plain shapes, and the modifier does the cutting for you.

1. The three operations

Select the object you want to keep, open the Modifiers tab as in Lesson 7, and add Boolean from the Generate group. Then pick the other object as the source. The manual describes the three choices under Operation. Difference cuts the source meshes out of the modified mesh, like a cookie cutter. Union adds the source meshes to the modified mesh and removes the faces hidden inside, so the two become one solid. Intersect keeps only the volume that is inside both the modified mesh and all of the source meshes.

2. Choose the source

Operand Type decides what the source is. The manual lists two choices. Object uses a single mesh object that you pick in the Object field, which is what the picture above does. Collection uses every mesh object in a collection you pick, so one modifier can cut or join many objects at once. The manual notes that with the Fast solver, a Collection source cannot use the Intersect operation. The source object stays in the scene; hide it or move it to another collection so you can see the result, as the manual's own example does.

3. Pick a solver

Solver chooses the algorithm. The manual lists three. Float is a simple solver with good performance, but it lacks support for overlapping geometry. Exact is a complex solver that gives the best results and fully supports overlapping geometry, but it is much slower. Manifold is usually the fastest, but it only works on manifold meshes, plus the special case of Difference with a plane. The manual also warns that only manifold meshes are guaranteed to give proper results, and that meshes with holes might give glitches and artifacts.

Read the manual page on the Boolean modifier.

Exercise

Add a cube, then add a UV sphere that overlaps one corner of it. Give the cube a Boolean modifier, pick the sphere as the source object, and switch the Operation between Difference, Union and Intersect to see all three results. Hide the sphere with the eye icon in the Outliner to see each result clearly.
