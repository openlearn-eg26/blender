Bonus lesson

The Curve Modifier

Garden hoses, curved railings and bent pipes all follow a path. The Curve modifier deforms a mesh along a curve object, so you model a straight piece and let the curve bend it. In the Array bonus lesson you met Fit Curve, which only counts copies. The Curve modifier is the one that actually bends the shape.

1. How it works

The manual describes the modifier like a train following rails. It works on one dominant axis, X by default. When you move your mesh along that axis, the mesh travels along the curve and deforms with it. Moving the mesh sideways, perpendicular to the axis, moves it closer to or further from the curve. The manual also notes that the modifier works in global space, so the actual position of the geometry relative to the curve decides the result.

2. Set it up

Model the straight object and give it enough geometry along its length to bend, for example with loop cuts or subdivisions. Add a curve object, such as a Bezier curve, and shape it in Edit Mode. Then select the mesh, open the Modifiers tab as in Lesson 7, add Curve from the Deform group, and pick your curve in Curve Object. The manual's advice: keep your object's origin at the center of its geometry (Set Origin to Geometry), and start with the object's origin at the same location as the curve object's origin. The snap tools from the cursor lesson help with that.

3. The options

Deformation Axis chooses the axis the curve deforms along: X, Y, Z or their negative directions. Pick the axis your object is longest on. Vertex Group restricts the effect to only the vertices in a group you choose, and Invert flips that, so the group marks the vertices that will not be deformed. The manual also notes that on a 3D curve, the Tilt value of the control points twists the deformed object, and the Radius property scales it; both live in the curve's Shape panel under Path/Curve-Deform.

Read the manual page on the Curve modifier.

Exercise

Add a cube, scale it into a long beam, and apply the scale as in the Apply Scale bonus lesson. In Edit Mode, add loop cuts along its length with Ctrl+R. Add a Bezier curve and bend it into an arch. Give the beam a Curve modifier, pick the curve, and slide the beam along X to watch it travel along the arch.
