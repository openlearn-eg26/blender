Basic Blender Shortcuts

All of these are default shortcuts in Blender 4.5 LTS and are used in the lessons.

ShortcutWhat it does
Shift + AAdd an object
G / R / SMove / rotate / scale
X / Y / ZLimit to an axis
Alt + G / R / SReset location / rotation / scale
TabEnter or leave Edit Mode
1 / 2 / 3Vertices / edges / faces (in Edit Mode)
EExtrude
IInset
Ctrl + RLoop Cut
Ctrl + BBevel
Shift + DDuplicate
A / Alt + ASelect all / deselect all
Numpad .Focus on the selection
HomeShow the whole scene
Numpad 0Camera view
Ctrl + Alt + Numpad 0Move the camera to the current view
NSide panel
F12Render an image
Ctrl + SSave
